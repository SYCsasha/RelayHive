# RelayHive 移动端UI壳子 (Mobile UI Shell)

## 📱 项目介绍

RelayHive 移动端UI壳子是基于 UI.md 和 UI.jpg 设计稿开发的，完全实现了UI视觉层的交互框架，**仅专注于UI壳子实现，不涉及业务功能逻辑**。

## 🎯 核心设计元素

### 1. **吉祥物交互中心 (⑨ Mascot)**
- 拟人化角色，具有左右两只手的动画
- 左手动作：扇巴掌拍击左侧边栏，触发左侧栏翻页
- 右手动作：抓取右侧边栏插件控制区
- 可点击手部进行交互

### 2. **左侧边栏 - AI员工组织架构 (Left Sidebar)**
三个视图可通过吉祥物左手扇巴掌切换：

#### 🟢 工位页 (Workstation)
- AI员工花名册
- 显示每个AI的信息卡片：头像、岗位、状态指示灯
- 配置按钮(⚙️)和工作区按钮(💼)

#### 🟡 生产流水日志 (Log Tracker)
- 实时滚动的任务日志显示
- 展示各个AI正在执行的任务

#### 🟣 事务大厅 (Task Hall)
- 任务发布和管理页面
- 显示待办、进行中的各类任务
- 优先级标签显示

### 3. **中央画布区 (⑯ Central Canvas)**
- **主要功能**：人类与吉祥物的日常沟通
- **情绪卡 (⑩)**：显示吉祥物的实时情绪状态
- **消息区**：聊天对话显示区域
- 可反转显示AI配置、工作区等

### 4. **右侧边栏 - 交付插件系统 (Right Sidebar)**
- **插件库 (⑪ Destinations)**
- 展示可用的交付目的地：
  - GitHub网页插件（代码提交）
  - 画廊展览馆（设计图提交）
  - 办公桌面（文档提交）
  - 数据仓库、云盘等
- 支持插件配置和状态管理

### 5. **底部输入控制区 (Bottom Input)**

#### ⑫ 主文本输入框
- 常规文本输入
- 支持 # 号标签协议命令

#### ⑬ 模型切换 (Model Switcher)
- 卡片反转动效
- 选择不同的AI模型（Gemini, Claude, GPT-4等）

#### ⑮ 多态语音按键 (Voice Button)
- 单击：激活"实时待机监听模式"（微光闪烁效果）
- 长按：常规语音转文字输入

#### ⑭ 文件上传按钮
- 支持文件上传功能

## 🛠️ 技术栈

- **框架**: React 18 with TypeScript
- **样式**: Tailwind CSS
- **构建工具**: Vite
- **开发服务器**: Vite Dev Server

## 🚀 快速开始

### 安装依赖
```bash
cd mobile-ui
npm install
```

### 开发模式
```bash
npm run dev
```
浏览器将自动打开 `http://localhost:5173`

### 构建生产版本
```bash
npm run build
```
生成的文件在 `dist/` 目录

### 预览生产构建
```bash
npm run preview
```

## 📝 使用说明

### 与吉祥物交互
1. **点击左手** - 打开/关闭左侧边栏
2. **点击右手** - 打开/关闭右侧边栏
3. **进入聊天** - 切换到消息输入界面

### 左侧边栏操作
- 点击三个彩球标签（🟢 🟡 🟣）切换不同视图
- 点击AI卡片上的按钮进行操作
- 在任务大厅中可以查看和管理任务

### 底部输入
- 输入普通消息或 # 开头的命令
- 点击🎤按钮进行语音输入
- 使用模型切换器选择不同的AI模型
- 📎 按钮用于文件上传

## 🔍 支持的标签协议示例

根据 UI.md 设计，系统支持以下标签格式：
- `#1_search` - 搜索类任务
- `#1_image` - 图像处理任务
- `#1_office` - 办公/文档任务
- `#1_music` - 音乐类任务
- `#1_video` - 视频处理任务

## 📱 响应式设计

该UI壳子采用移动优先的设计理念，支持：
- 手机屏幕（375px - 600px）
- 平板屏幕（600px - 1024px）
- 桌面屏幕（1024px+）

## ⚠️ 重要说明

**这是一个UI壳子项目，关键特性：**
- ✅ 实现所有UI布局和交互框架
